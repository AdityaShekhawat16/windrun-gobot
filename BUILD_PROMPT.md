# WINDRUN v1.2 — Implementation brief (Art Foundation)

Use the existing working WINDRUN v1.1 Godot/GDScript game as the starting point.
Preserve physical movement, control mapping, jumps, terrain collision, save data,
world streaming, races, exploration markers and audio. Upgrade **graphics**:
painted alpha-cut grass and flowers, believable grass color variation,
panoramic and billboard cloud layers, textured leaf-crown shading, and a closer
camera at superhuman speeds. Keep shader assets modular and editable. Deliver a
complete offline Godot project compatible with Godot 4.4+ Compatibility renderer
and a 30–60 FPS **goal** on Intel integrated graphics. Verify asset paths and ZIP
integrity; do not claim that Godot was playtested unless an engine ran.
